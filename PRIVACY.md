# Privacy

LexiLift runs entirely in the user's browser.

- No account is required.
- No advertising or analytics code is included.
- Learning progress is stored in browser local storage.
- Question-quality reports are stored locally unless the user exports them.
- Speech recognition, when supported and selected by the user, is provided by the browser and may follow the browser vendor's privacy terms.
- Clearing site data may erase progress, so users should export a backup before changing devices or browsers.
