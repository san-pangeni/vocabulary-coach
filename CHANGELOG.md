# Changelog

## 4.0.0 - Mobile Edition

- Rebuilt the interface mobile-first.
- Replaced the large single-file application with a small shell and on-demand lesson chunks.
- Added fixed bottom navigation and a desktop sidebar.
- Hid navigation during questions to increase usable phone space.
- Added expandable context panels that preserve rich situations without overwhelming the screen.
- Shortened mechanical directions while preserving detailed question context.
- Added sticky answer controls and larger touch targets.
- Replaced the wide vocabulary table with searchable mobile cards.
- Added installable Progressive Web App metadata and offline caching.
- Added safe-area support for modern iPhones.
- Added automatic GitHub Pages deployment for a `USERNAME.github.io` repository.
- Preserved separate recognition, recall, grammar, collocation, production, retention, and pronunciation evidence.
