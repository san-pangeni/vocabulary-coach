# Contributing

Contributions are welcome, especially reports involving:

- weak or repetitive context
- more than one plausible answer
- grammar or collocation problems
- unnatural American English
- inaccurate meaning, register, or pronunciation guidance
- mobile accessibility and usability

When reporting a language issue, include the target expression, exercise type, complete prompt, proposed correction, and a brief explanation.

For code changes, test the app at approximately 390 x 844 pixels and at a desktop width of at least 1200 pixels. Keep the application dependency-free and preserve offline operation.
